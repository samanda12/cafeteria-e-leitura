# ☕ Café & Páginas

Primeira versão visual do projeto de cafeteria literária virtual.

## O que já existe

- Home vintage responsiva
- Biblioteca com filtros por gênero
- Busca de livros
- Cafeteria literária
- Clube dos leitores
- Rádio com player visual de demonstração
- Modo preparado para leitura gratuita
- Identidade visual em estilo vintage / cozy / literary café

## Abrir

Basta abrir `index.html` no navegador.

## Próximas etapas recomendadas

1. Criar backend com Node.js + Express.
2. Criar banco MySQL.
3. Criar cadastro/login.
4. Criar tabela de livros e autores.
5. Integrar obras em domínio público/licenciadas.
6. Criar leitor de livros (PDF/EPUB, conforme licenças).
7. Criar estante pessoal.
8. Criar comunidade com posts, comentários e curtidas.
9. Criar painel administrativo.
10. Integrar uma fonte de áudio licenciada para a rádio.

## Direitos autorais

Não faça upload ou disponibilize livros protegidos por direitos autorais sem autorização. Para a biblioteca pública, use obras em domínio público, licenças que permitam distribuição ou obras cedidas pelos autores.
