A Cafeteria Literária é um projeto de extensão desenvolvido com o objetivo de incentivar o hábito da leitura e ampliar o acesso à literatura por meio da tecnologia.

O projeto consiste no desenvolvimento de um site que reúne um ambiente virtual acolhedor, inspirado em uma cafeteria, onde os usuários podem conhecer e acessar conteúdos literários de forma gratuita. A plataforma foi pensada para disponibilizar diferentes gêneros, como romance, ficção, suspense, aventura e mangás, proporcionando uma experiência simples, agradável e acessível para leitores.

Além de promover o acesso à leitura, o projeto busca utilizar os conhecimentos adquiridos no curso de Análise e Desenvolvimento de Sistemas para desenvolver uma solução tecnológica com finalidade educacional e social.

Durante o desenvolvimento, foram aplicados conhecimentos de desenvolvimento web, organização de conteúdo, estruturação de páginas, design de interfaces e experiência do usuário

A proposta é unir tecnologia, educação e cultura em um único ambiente digital, tornando a leitura mais acessível e incentivando pessoas de diferentes idades a descobrir novos livros e desenvolver o hábito de ler.
